# 平台功能与应用场景

## 技术架构

系统为综合性集成光伏监测与维护平台，涵盖从数据采集到故障处理的全方位流程：

- 软件采用 B/S 结构：应用程序的逻辑和数据存储在服务器上，客户端（浏览器）通过网络请求数据和执行交互操作。
- 前端使用 React、Echarts、ant-design 等框架进行三维模型渲染、巡检结果展示、诊断数据展示以及用户操作接收；地图框架采用 Cesium 和 turf。
- 后端负责巡检影像处理、光伏组件提取与故障识别、矢量与三维模型的转换与管理、数据库访问与查询。
- 数据处理主要使用 C++ 和 Python 语言，利用 HRNet 深度学习模型进行光伏组件亮斑提取与故障识别；前端通信与数据查询部分使用 Java 语言，关键技术包括 spring 和 springboot；数据库采用 MySQL。

多传感器数据融合技术增强了数据的可靠性和准确性，结合热成像、可见光、红外等多源信息，提升了系统在不同环境和复杂条件下的故障诊断能力；该技术在数据缺失或异常时通过冗余信息确保分析结果的可靠性。

## 五大数据服务功能

1. 无人机智能化巡检：通过无人机搭载的先进传感器和高分辨率摄像设备，实现对光伏组件表面的高精度拍摄和检测，实时获取海量数据；结合人工智能算法深度分析处理，识别微小的缺陷或潜在故障点，实现早期预警和即时干预。
2. 时间序列预测：分析历史监测数据和运维记录，利用机器学习模型对光伏电站未来运行状态进行预测，涵盖环境因素变化影响与组件性能长期趋势分析。
3. 结果三维可视化：将复杂的数据和检测结果以三维方式呈现，支持从不同角度和层面理解复杂的光伏电站布局与组件安装角度。
4. “病历”档案可追溯：每个光伏组件的历史数据和运维记录系统化管理，构建类似医疗病历的档案体系，支持即时查询和长期追踪。
5. 运维方案自动生成：基于大量的运维数据和大模型，自动化生成特定情况下的运维方案，快速响应运行状态变化。

平台还支持组件管理，允许用户以组串或单个组件为单位进行管理；支持用户根据系统提示决定是否采取维护措施，并自动生成维护记录，以文档形式保存便于查阅和分析。

## 场景一：集中式光伏场站维护

大型光伏场站通常分布在山地、荒漠、滩涂等地区，最多可能拥有数十万甚至上百万的光伏组件，带来两个挑战：故障检测耗时长、难度大；维护资源分配复杂、性能优化需求高。

系统的应对方式：通过无人机的灵活性和机动性，在山地和滩涂等难以人工作业的地区实现高效快速巡检，影像传输至云端服务器后由 AI 算法识别微小缺陷、污渍或遮挡；同时收集光伏运行数据、空气数据、光照强度数据等多类型数据，识别优化机会并制定场站整体优化方案——例如建议批量调整光伏组件的倾斜角度或方向以适应不同季节的太阳辐射角度；结合天气条件、季节变化和电网需求动态调整运行策略，对人员、设备和时间等维护资源进行科学分配。

## 场景二：分布式光伏巡检

分布式光伏遍布居民区屋顶、工业园区、农村地带等，屋顶厂房是主要承载形式，传统人工巡检面临三个问题：需要覆盖众多分散地点、屋顶故障难以快速维护并可能对建筑产生安全威胁、需要个性化维护方案。

系统通过无人机实现对屋顶光伏的详细检查，避开人工上屋顶的安全问题；图像传输到云平台后由图像处理和机器学习算法识别灰尘积累、遮挡物、损伤或性能退化迹象；进一步根据地理位置、历史性能数据和预期天气条件，为每个分布式系统制定维护计划，并通过远程诊断提供故障处理建议或自动调整系统设置，减少现场维护需求。

## 场景三：循环经济

光伏行业在循环经济场景下面临光伏组件回收再利用效率低、环境影响评估复杂、资源优化配置难等问题。系统利用无人机搭载的传感器收集光伏组件性能衰减、物理损伤及环境影响因素等数据，评估组件的当前状态和预期寿命，识别即将到达生命周期末期的组件及其部件，为回收、再利用或替换提供依据；并可计算光伏组件的碳足迹、能耗以及可能产生的污染物，帮助企业和相关组织优化生产流程、选择更环保的材料与技术。系统还能对光伏组件的生产、使用和回收过程中产生的环境影响进行全面评估，为光伏行业的循环经济实践提供技术支持。

## 技术成熟度与开发进展

- 无人机巡检技术：已于多家光伏电站试飞，实现了光伏组件的高精度数字定位、自动飞行及图像收集、图像自动切割处理入库的自动化巡检流程；相关部分已完成专利申请。
- 多传感器融合的光伏电站运维技术：已为多家光伏电站提供多模态运维管理，实现组件输出功率预测、故障检测等功能；对未来的合作电站，现有技术仅需少量数据采集和模型输入即可实现高精度运维；相关部分已作为功率预测模型训练方法完成专利申请。
- 人工智能故障诊断分析技术：通过与光伏电站的合作和功率预测服务，收集了大量光伏组件运行数据及红外图像和可见光图像库，已构建完成光伏组件运行状态数据库并训练得到基于 AI 的光伏组件故障诊断算法，实现组件级别的光伏故障诊断，可识别包括子串开路、组件短路、子串短路、杂物遮挡等近 10 种故障类型；相关部分已完成专利申请。
- 机器人自动清洁技术：已实现光伏板清洁机器人基本功能，可起降到特定需要作业的光伏组件并进行清理作业；机器人已具备远程遥控驾驶和无人驾驶两种工作模式，可对接无人机通信、检测光伏板脏污情况并引导清洁机器人作业，与光伏医生运维系统形成管理闭环。

## 能力的可迁移性

故障识别模型不仅可以应用于光伏组件缺陷检测，还可以迁移至风电叶片检测、电网线路巡检领域；无人机机库支持 10km 半径自主飞行，适配山地、沙漠、高山、近海等复杂地形和环境。

## 平台有哪些功能

平台提供五大数据服务功能：无人机智能化巡检、时间序列预测、结果三维可视化、“病历”档案可追溯、运维方案自动生成；此外支持以组串或单个组件为单位的组件管理、维护记录自动生成与巡检报告查看。

## 常见问题

**平台是怎么看结果的？** 浏览器访问的 web 系统：三维模型渲染巡检结果与诊断数据，支持三维可视化、病历式组件档案查询和巡检报告查看。

**只有无人机没有平台吗？** 是软硬件一体的系统：无人机、传感器、清洁机器人与 B/S 架构的运维平台配合使用，兼容主流无人机硬件与光伏管理系统。
