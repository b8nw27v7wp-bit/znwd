# 光伏医生系统总览

## 系统定位

“光伏医生”是面向光伏电站的智能光伏巡检与维护系统，通过集成无人机巡检技术、多传感器数据融合、人工智能分析技术和机器人自动清洁技术，实现光伏电站的全面智能化监控和高效维护。

系统作为集巡检、诊断、清洁于一体的光伏电站巡检解决方案，旨在解决光伏电站在运营与维护中遇到的数据采集、分析和清洁难题，解决运维中的高成本、低效率等问题，使光伏电站的运维迈向智能化、自动化的新时代。

## 四项核心技术构成

| 技术方向 | 作用 |
| --- | --- |
| 无人机巡检技术 | 具备自主导航和精准定位能力，高效覆盖大面积光伏电站，完成高分辨率成像和数据采集 |
| 多传感器融合的光伏电站运维技术 | 融合热成像、可见光、多光谱传感器数据，提供全面的光伏组件状态评估 |
| 人工智能故障诊断分析技术 | 深度挖掘运行数据与图像数据，提供预测性维护建议 |
| 机器人自动清洁技术 | 自动识别并清除光伏组件表面的灰尘和异物，保持光伏组件高效运作 |

四类技术在系统中协同工作：自动清洁机器人与无人机巡检系统协同，形成闭环光伏运维管理系统，全面保障光伏电站的长期高效运行。

## 巡检体系与闭环

产品通过“空天地一体化”巡检体系（无人机 + AI 诊断），满足客户对效率提升、故障精准识别及发电优化的核心诉求：为电站业主和运营商降低运维成本（传统人工巡检效率低）、减少发电损失，预防热斑效应等安全隐患。

运维闭环的形态是：无人机采集巡检数据 → AI 分析诊断故障与积污 → 输出维护与清洁作业需求 → 清洁机器人与运维动作执行 → 结果回到系统留档。

## 交付形态

- 开发基于 B/S 架构的 web 形式运维系统，融合无人机调度、巡检、路径规划，以及图像采集与处理、数据分析、故障诊断等功能。
- 兼容主流无人机硬件与光伏管理系统，降低客户迁移成本。
- 软件安装后系统部署在用户本地电脑：软件启动后自动运行前端与后端服务组件，用户通过浏览器访问前端界面进行操作。

## 系统覆盖的场景

- 集中式地面电站：针对戈壁、沙漠等大型电站的组件热斑、隐裂等问题，通过无人机集群实现电站的数小时快速巡检，结合三维数字孪生技术实现设备精准定位与故障预警。
- 分布式光伏系统：适用于工商业屋顶、农村户用等场景，解决分散式运维难题，通过 AI 算法分析发电效率损失（如灰尘遮挡、低效设备）并给出优化建议。
- 海上光伏电站：应对高盐雾、强风浪、生物附着等复杂环境，通过“三维立体化”技术架构提供全天候、全场景的运维支持。
- 光伏 + 农业：面向“板上发电、板下种植/养殖”的农光、渔光模式，实现光伏集群的智能化管理，提升闲置资源利用率。

## 常见问题

**光伏医生是做什么的？** 面向光伏电站的智能巡检与维护系统，把无人机巡检、多传感器数据融合、AI 故障诊断和机器人自动清洁集成在一起，形成从数据采集到清洁维护的闭环。

**清洁和检测是不是同一套系统？** 是同一套系统里的两部分能力：无人机巡检负责发现缺陷与污染位置，机器人负责清洁执行，两者共用同一套数据与台账。
