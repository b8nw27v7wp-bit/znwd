# 两栖光伏清洁机器人产品概述

## 产品定位

两栖光伏清洁机器人通过无人机与履带小车装配的形式，完成“空中巡检、陆地作业”的两栖工作形式。它面向荒漠、戈壁、高山、海上等地区的大型光伏电站，以及工商业屋顶等分布式场景，替代人工清洗与高压清洗无人机作业。

产品不仅要提高清洗效率、降低维护成本，还要避免光伏电板损害和安全风险，对于保障光伏电站的高效稳定运行具有重要意义。

## 空地两栖的构成

- 空中部分：巡检无人机负责识别污染与故障，并引导清洁作业。
- 地面部分：履带式清洁机器人在光伏板上平稳行走、执行精细清洗，清洗完成后自动返回基地。
- 两者配合形成的形态表述为“空中巡检、陆地作业”。（申报书中另有“清洁无人机搭载履带清洁装置”的表述方式。）

## 整机与作业参数

| 项目 | 参数 |
| --- | --- |
| 整机重量 | 仅重 23kg |
| 对光伏面板压强 | 约 1.6kPa，低于光伏面板承受压强标准 |
| 行走方式 | 履带式，履带经特殊防滑设计，遇水增强摩擦力，不损伤光伏板 |
| 防护等级 | 设计防风防尘外壳，确保设备达到 IP67 防护等级 |
| 工作模式 | 远程遥控与自主导航两种；可对接光伏医生，由无人机检测光伏板脏污情况引导清洁机器人作业 |

## 控制与通讯方式

通过 CAN 通讯，可在上位机实现对机器人的驱动和控制，实时获取状态信息并传输工况给客户端。设备具备自动驾驶、智能巡逻、远程监控以及无人机指挥联合运动等功能，并提供基于 ROS 的 CAN 通讯包，方便用户二次开发。

## 适用场景

- 荒漠、戈壁地区建设的大型光伏电站：规模较大，清洗难度大，人工成本较高，需要清洗效率、自动化程度更高的清洗方案。
- 高山、海上等人烟稀少、太阳辐射量大的区域：对光伏运维操作员的专业技能和经验要求大，人工成本较高。
- 集中式地面电站与分布式光伏系统：申报书中列为系统的主要应用场景。

## 光伏电站组件积灰怎么处理

巡检环节通过积尘度评估判断组件表面的积灰与污染程度，发现积灰、污渍后引导清洁机器人定点清洗；组件表面的灰尘与异物由清洁机器人自动识别并清除，避免积灰造成的发电损失。

## 光伏展区展示什么

展板介绍两栖光伏清洁机器人（空中巡检、陆地作业）与“光伏医生”智慧运维系统：机器人本体的结构、材料与清洁作业方式，以及无人机巡检、缺陷诊断、清洁执行与数据平台的整体方案和落地成效。

## 清洁机器人怎么收费

按电站规模阶梯收费：集中式电站（≥50MW）基础巡检年费 5-8 万元/GW、AI 深度诊断 3 万元/次、机器人清洁包 2 万元/GW/年；分布式电站（＜50MW）基础巡检年费 0.5-1 万元/MW、AI 深度诊断 0.3 万元/次。设备销售与租赁、服务订阅的完整定价表与成本核算见「商业模式与定价」。

## 常见问题

**两栖是什么意思？** 指“空中巡检、陆地作业”两种作业形式：无人机在空中巡检发现污染与缺陷，履带式清洁机器人在地面（板面）完成清洗。

**光伏清洁机器人是做什么的？** 面向光伏电站组件表面的自动化清洁，替代人工清洗与高压清洗无人机，降低维护成本并避免人员高处作业风险。
