# 光伏清洁无人机产品概述

## 产品定位

面向光伏电站组件表面清洁的专用无人机系统，适用于集中式电站与分布式屋顶场景。

## 核心能力

- 组件表面灰尘、鸟粪等污染物识别
- 规划航线自动清洁作业
- 清洁前后发电效率对比（需配合监测数据）
- 支持人工遥控与半自动模式

## 适用场景

| 场景 | 说明 |
|------|------|
| 集中式地面电站 | 大面积组件巡检式清洁 |
| 工商业屋顶 | 狭窄通道、高空组件 |
| 临水/复杂地形 | 减少人员上阵风险 |

## 常见问题

**光伏清洁无人机做什么？** 通过飞行平台对光伏组件进行表面清洁，降低积灰导致的发电损失。
