# 风场检测无人机产品概述

## 产品定位

面向风电场风机叶片与塔筒外观缺陷的空中检测系统，辅助运维决策。

## 核心能力

- 叶片裂纹、涂层脱落、雷击痕迹等图像采集
- 航线化重复巡检，结果可对比
- 缺陷位置标注与报告输出（可对接运维平台）
- 降低停机攀爬与吊篮检测风险

## 适用场景

| 场景 | 说明 |
|------|------|
| 陆上/海上风电场 | 常规周期巡检 |
| 大风后复检 | 突发天气后的专项检查 |
| 机组改造前后 | 叶片维修效果验证 |

## 常见问题

**风场检测无人机是做什么的？** 用无人机对风机叶片、塔筒等部位做空中检测，发现缺陷并生成报告。
